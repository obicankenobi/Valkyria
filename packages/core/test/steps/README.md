# Stegtester

Ett testfilspar per fil i `resolve/steps/`, mot ett handbyggt minimalt `GameState` — inte ett
fullt scenario. Ett steg som kräver ett fullt scenario för att testas är för hårt kopplat och
ska brytas upp. Se ETAPP1_TEKNISK_SPEC.md avsnitt 7.1.

Byggs allteftersom respektive steg implementeras, P2–P8.
